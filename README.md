# 🔀 C Programming – Conditional Statements Exercises

This project contains beginner-level **C programming exercises focused on conditional statements, comparisons, and basic algorithmic logic**.

---

# 📌 Basic Problems

---

## 1️⃣ Even or Odd

Checks whether a number is even or odd.

### 🧠 Idea

* `num & 1` → odd
* otherwise → even

---

## 2️⃣ Maximum of Two Numbers

Prints the larger of two integers.

### Output

* Larger number
* `"Equal"` if both numbers are the same

---

## 3️⃣ Simple Calculator

Performs basic arithmetic operations:

* `+`
* `-`
* `*`
* `/`

### ⚠️ Special Case

* Division by zero → `"Error"`

---

## 4️⃣ Age Category

Classifies a person based on age:

| Range | Category |
| ----- | -------- |
| < 13  | Child    |
| 13–17 | Teen     |
| 18–64 | Adult    |
| 65+   | Senior   |

---

## 5️⃣ Day of Week

Converts a number (1–7) into a weekday.

---

## 6️⃣ Grade Description

Maps grades to meaning:

| Grade | Meaning   |
| ----- | --------- |
| A     | Excellent |
| B     | Good      |
| C     | Average   |
| D     | Poor      |
| F     | Fail      |

---

# 📌 Advanced Problems

---

## 7️⃣ Max & Min Functions

* Find the maximum of two numbers
* Find the minimum of three numbers

### 🧠 Idea

Uses helper functions:

* `max_element(a, b)`
* `min_3_element(a, b, c)`

---

## 8️⃣ Sort Three Numbers (Ascending Order)

Reads three integers and prints them in sorted order.

### 🧠 Idea

* Compare and swap using a temporary variable

---

## 9️⃣ FizzBuzz

### Rules:

| Condition            | Output   |
| -------------------- | -------- |
| divisible by 3 and 5 | FizzBuzz |
| divisible by 3       | Fizz     |
| divisible by 5       | Buzz     |
| otherwise            | Nothing  |

---

## 🔟 Vowel or Consonant

Checks whether a character is a vowel:

`a, e, i, o, u` (uppercase and lowercase supported)

---

## 1️⃣1️⃣ Range Check

Checks whether a number is within range:

```text id="range"
10 ≤ number ≤ 100
```

### Output:

* `"Within range"`
* `"Out of range"`

* bitwise operator (`&`)

* user input (`scanf`)
